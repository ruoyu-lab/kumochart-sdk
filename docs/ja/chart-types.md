# チャートタイプ

コアには 11 種類のシリーズ（ローソク足、ライン、エリアなど。[外観](appearance.md#メインシリーズ)を参照）が組み込まれています。チャートタイプモジュールは、さらに次のものを追加します。

| タイプ                                 | エクスポート名  | 仕組み                                                                     |
| -------------------------------------- | --------------- | -------------------------------------------------------------------------- |
| 平均足（Heikin-Ashi）                  | `heikinAshi`    | 各足を、その足と 1 本前の足の平均から作る。トレンドがなめらかに見える      |
| 練行足（Renko）                        | `renko`         | 価格が 1 ボックス分動くたびにボックスを 1 つ描く。時間は関係ない           |
| レンジバー                             | `rangeBars`     | 各足の高値から安値までの幅がちょうど一定になる                             |
| 新値足（Line break）                   | `lineBreak`     | 終値が直前の数本の最高値か最安値を抜けたときだけ、新しい足を描く           |
| カギ足（Kagi）                         | `kagi`          | 終値が逆方向に一定幅以上動いたときだけ折り返す。線の太さで陽線・陰線を表す |
| ポイント＆フィギュア（Point & figure） | `pointFigure`   | 上昇を X、下落を O で描き、逆方向に一定のボックス数動いたら列を替える      |
| ティックバー                           | `tickBars`      | 一定の約定回数ごとに 1 本                                                  |
| 出来高バー                             | `volumeBars`    | 一定の出来高ごとに 1 本                                                    |
| 売買代金バー                           | `turnoverBars`  | 一定の売買代金ごとに 1 本                                                  |
| 出来高ローソク足                       | `volumeCandles` | ローソク足の幅が出来高に応じて変わる                                       |

```ts live height=400
import { createChart } from '@kumochart-sdk/core';
import { chartTypes, renko } from '@kumochart-sdk/core/chart-types';
import { loadBars } from '@docs/data';

const chart = createChart(document.getElementById('chart')!, {
  modules: [chartTypes([renko])]
});

chart.data.set(await loadBars(), { interval: '1m' });
chart.data.setTimeframe('1h');
chart.transforms.set({ type: 'renko' }); // ボックスのサイズはデフォルトで 14 本のアベレージ・トゥルー・レンジから自動で決まる
```

## 2 種類のチャートタイプ

チャートタイプには 2 つのやり方があります。

- **足を作り直す**：平均足、練行足、レンジバー、新値足、ティックバー、出来高バー、売買代金バーは `chart.transforms.set()` でオンにします。現在の時間足のローソク足から新しい足の並びを作って表示します。
- **描き方を変える**：出来高ローソク足は `mainSeries.type` で切り替えます。ローソク足そのものは元のままです。

カギ足とポイント＆フィギュアは両方が必要です。まず足を作り、それから描き方を変えます。

```ts
// 練行足
chart.transforms.set({ type: 'renko', params: { box: 500 } });

// カギ足：カギ足のラインを作り、カギ足の描き方で描く
chart.batch(() => {
  chart.transforms.set({ type: 'kagi' });
  chart.applyOptions({ mainSeries: { type: 'kagi' } });
});

// 出来高ローソク足
chart.applyOptions({ mainSeries: { type: 'volume-candles' } });

// 通常のローソク足に戻す
chart.transforms.set(null);
chart.applyOptions({ mainSeries: { type: 'candles' } });
```

作られた足が、チャートの「表示される足」になります。インジケーターはそれをもとに計算し、`chart.data.toArray()` で読めるのもそれです。元のデータは変わらないので、オフにすれば元に戻ります。

## パラメーター

| タイプ               | `type`         | パラメーター                                                                                                                                                                                                                                                                |
| -------------------- | -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 平均足               | `heikin-ashi`  | なし                                                                                                                                                                                                                                                                        |
| 練行足               | `renko`        | `box` で固定のボックスの高さ、または `percentage` で最新価格に対する割合を指定する。どちらも指定しなければ `atrLength`（デフォルト 14）本のアベレージ・トゥルー・レンジを使う。`source` は `close`（デフォルト）か `ohlc`。`wicks` はヒゲを描くかどうか（デフォルトは描く） |
| レンジバー           | `range`        | `range` で各足の幅を指定する。指定しなければ 14 本のアベレージ・トゥルー・レンジを使う                                                                                                                                                                                      |
| 新値足               | `line-break`   | `lines` で何本前までを抜けたら新しい足にするか（デフォルト 3）                                                                                                                                                                                                              |
| カギ足               | `kagi`         | `reversal` で固定の転換幅、または `percentage` を指定する。どちらも指定しなければ `atrLength` 本のアベレージ・トゥルー・レンジを使う                                                                                                                                        |
| ポイント＆フィギュア | `point-figure` | `box`、`percentage`、`atrLength` のいずれかでボックスのサイズを決める。`reversal` は列を替えるのに必要な逆方向のボックス数（デフォルト 3）。`source` は `close` か `hl`。`oneStepBack` で 1 ボックスだけの列の転換を許可する                                                |
| ティックバー         | `tick`         | `count` で 1 本あたりの約定回数（必須）                                                                                                                                                                                                                                     |
| 出来高バー           | `volume`       | `volume` で 1 本あたりの出来高（必須）                                                                                                                                                                                                                                      |
| 売買代金バー         | `turnover`     | `turnover` で 1 本あたりの売買代金（必須）                                                                                                                                                                                                                                  |

### 自動のサイズ

固定のサイズを指定しないときは、これらの足を作る時点で直近の確定足からサイズを決めます。アベレージ・トゥルー・レンジなら直近の確定足までの `atrLength` 本（デフォルト 14 本）のアベレージ・トゥルー・レンジ（形成中の最新の足は含めない）、割合なら最新価格に対する割合で、読みやすい数に丸めます（2137 なら 2000）。

その後リアルタイムで届く足ではサイズは変わらず、次に作り直すまでそのままです。変換の設定、`data.set()`、時間足の切り替え、過去のデータの読み込み（`data.prepend()`）、リプレイの開始で作り直し、そのときの直近の確定足で計算し直します。過去のデータを読み込んでも直近の足は変わらないので、サイズはふつう変わりません。

確定した足が `atrLength` 本に満たずサイズを決められないうちは何も描きません。そろったら、その時点の確定足でサイズを決めて固定し、最初の足から描きます。割合で足がまったくない状態から始めたときは、最初の足が確定するのを待ち、その終値で計算します。

約定から作る（下記）ときは、1 件の約定は価格が一つだけでトゥルー・レンジがありません。固定のサイズか `percentage` を、レンジバーなら `range` を指定してください。指定しないとエラーになります。

自動で計算されたサイズは読み出せるので、画面に表示するのに使えます（まだ決まっていないときは `resolved` が `null` です）。

```ts
chart.transforms.get();
// { type: 'renko', params: {}, input: 'bars', resolved: { box: 500, ... } }
```

## 約定（ティック）から作る

ティックバー、出来高バー、売買代金バーは、デフォルトでは現在の時間足のローソク足から合成するので、1 本の足が分割されることはありません。本当に 1 件ずつの約定から作りたいときは `input: 'trades'` を設定し、約定をチャートに渡します。

```ts
chart.transforms.set({ type: 'tick', params: { count: 100 }, input: 'trades' });
chart.data.addTrades(trades);
```

チャートはこれらの足を作るために直近の約定を保持します。保持する量は `performance.maxTrades`（デフォルト 10 万件）で決まります。この場合、`data.set()` でローソク足の `interval` を指定しておく必要があります。[データ](data.md#約定ティック)を参照してください。

## 保存

`saveState()` はローソク足の変換とメインシリーズの描き方を保存し、レイアウトを復元するときに一緒に設定し直します。[保存と復元](state.md)を参照してください。

独自のローソク足の変換や描き方を作るには、[カスタムシリーズ](custom-series.md)を参照してください。
