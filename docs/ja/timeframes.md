# 時間足と取引カレンダー

1 分足を渡せば、チャートは 5 分足、4 時間足、日足、週足などをブラウザ上で合成できます。時間足を切り替えるたびにサーバーへデータを要求する必要はありません。どう合成するかは取引カレンダーに従います。1 日が何時に始まるか、どんな取引セッションがあるか、どの曜日に取引するか、です。

## 時間足の書き方

数字と単位で書きます。

| 単位 | 意味 | 例             |
| ---- | ---- | -------------- |
| `s`  | 秒   | `'15s'`        |
| `m`  | 分   | `'1m'`、`'5m'` |
| `h`  | 時間 | `'1h'`、`'4h'` |
| `D`  | 日   | `'1D'`         |
| `W`  | 週   | `'1W'`         |
| `M`  | 月   | `'1M'`、`'3M'` |

大文字と小文字を区別するのは分の `m` と月の `M` だけで、それ以外はどちらで書いてもかまいません（`'4H'`、`'1d'`）。数字が 1 なら省略でき、`'D'` は `'1D'` と同じです。`{ unit: 'hour', count: 4 }` のようにオブジェクトで書くこともできます。

## 時間足を切り替える

```ts live height=360
import { createChart } from '@kumochart-sdk/core';
import { loadBars } from '@docs/data';

const chart = createChart(document.getElementById('chart')!);

chart.data.set(await loadBars(), { interval: '1m' });
chart.data.setTimeframe('4h');
```

`set()` で渡した `interval` が元の時間足で、`setTimeframe()` で設定するのが表示する時間足です。`setTimeframe(null)` で元の時間足に戻ります。

```ts
chart.data.sourceInterval(); // { unit: 'minute', count: 1 }
chart.data.timeframe(); // { unit: 'hour', count: 4 }。元の時間足のときは null
```

合成された足は、時間がその時間足の開始時刻、始値が最初の足の始値、高値と安値がすべての足の中の最高値と最安値、終値が最後の足の終値、出来高がその合計になります。最新の足はリアルタイムデータに合わせて更新されます。

数日で 1 本の時間足（`'2D'` など）は取引日で数えます。1 本はちょうどその数の連続した取引日（カレンダーの `weekdays`）で、取引のない日は数えず、時間はそのうち最初の取引日です。1970 年 1 月 1 日から順に区切るので、同じカレンダーならいつも同じ区切りになります。

インジケーターもチャートより長い時間足で計算できます。たとえば 5 分足のチャートに 1 時間足の移動平均線を表示できます。[インジケーター](indicators.md#別の時間足で計算する)を参照してください。

## 合成できる時間足

- 秒・分・時間：元の時間足の整数倍である必要があります。たとえば 1 分足からは 3 分足や 1 時間足を合成できますが、90 秒足は合成できません。
- 日：元の時間足で 1 日を割り切れる必要があります。たとえば元の時間足が 1 分、15 分、4 時間ならどれも合成できますが、7 分では合成できません。
- 週・月：1 日を割り切れる時間足か、1 日足から合成します。2 日足からは合成できません。
- 元の時間足より短い時間足は作れません。

合成できない時間足を指定すると、`setTimeframe()` はエラーになり、その理由を示します。時間足のメニューを作るときは、先に `canBuildTimeframe()` でどれを選べるかを判定できます。

```ts
import { canBuildTimeframe } from '@kumochart-sdk/core';

canBuildTimeframe('4h', '1h'); // true
canBuildTimeframe('1W', '2D'); // false
```

秒・分・時間の周期は長さが決まっていて、`intervalDuration()` がそのミリ秒数を返します。日・週・月の長さは取引カレンダーで決まるため、`null` を返します。

```ts
import { intervalDuration } from '@kumochart-sdk/core';

intervalDuration('15m'); // 900000
intervalDuration('1D'); // null
```

## タイムゾーン

タイムゾーンの設定は 2 つあります。

- `timeZone`：軸とクロスヘアの時間を、どのタイムゾーンで表示するか。設定しなければユーザーのパソコンのローカルタイムゾーンです。
- `calendar.timeZone`：足の日足や週足をどのタイムゾーンで区切るか、また時間単位の足が何時から始まるか。デフォルトは `UTC` です。

暗号資産取引所の足は UTC で区切られ、日足は UTC 0 時に始まるので、デフォルトのままで合います。表示される時間はユーザーのローカル時間のままです。株式や先物など、取引所の時間で足を渡す場合は、取引所のタイムゾーンを設定します。

```ts
createChart(container, {
  timeZone: 'Asia/Shanghai', // 時間を北京時間で表示
  calendar: { timeZone: 'America/New_York' } // 米国株：日足はニューヨークの 0 時から
});
```

カレンダーはデータと合っている必要があります。分足と時間足は、カレンダーの足の始まりに時間がなければなりません。たとえば UTC の正時に始まる時間足を、30 分ずれたインド時間のカレンダーに渡すと、`set()` はエラーを出してどう設定すればよいかを伝えます。足を黙って別の時間に動かすことはしません。日足・週足・月足は取引日で決まるので、時間がその日の 0 時でも、始値や終値の時刻でもかまいません。

タイムゾーンは IANA の名前で指定します。たとえば `Asia/Shanghai`、`America/New_York`、`UTC` です。

## 取引セッション

24 時間取引の市場では設定は不要です。取引時間が決まっている市場では、`calendar` に書いておきます。

| オプション  | 意味                                                                                                                                  | デフォルト    |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------- | ------------- |
| `sessions`  | 1 日の中の取引セッション。`'HH:MM-HH:MM'` で書き、終了が開始より早いときは午前 0 時をまたぐことを表す。セッション外の時間は捨てられる | `[]`（終日）  |
| `dayStart`  | 取引日が何時に始まるか。この時刻以降は翌取引日として扱う                                                                              | `'00:00'`     |
| `weekdays`  | どの曜日が取引日か。0 は日曜日                                                                                                        | 毎日          |
| `weekStart` | 週足が何曜日から始まるか。0 は日曜日                                                                                                  | `1`（月曜日） |

いくつかの例です。

```ts
// 中国 A 株：午前と午後の 2 つのセッション、月曜から金曜まで
createChart(container, {
  calendar: {
    timeZone: 'Asia/Shanghai',
    sessions: ['09:30-11:30', '13:00-15:00'],
    weekdays: [1, 2, 3, 4, 5]
  }
});

// 夜間取引のある中国の先物：21 時に始まる夜間取引は翌取引日に含め、金曜の夜間取引は月曜の取引日に含める
createChart(container, {
  calendar: {
    timeZone: 'Asia/Shanghai',
    sessions: ['21:00-02:30', '09:00-10:15', '10:30-11:30', '13:30-15:00'],
    dayStart: '21:00',
    weekdays: [1, 2, 3, 4, 5]
  }
});

// FX：ニューヨーク時間の午後 5 時に日付が変わる
createChart(container, {
  calendar: {
    timeZone: 'America/New_York',
    dayStart: '17:00',
    weekdays: [1, 2, 3, 4, 5]
  }
});
```

取引セッションがあるときは、時間単位の足は各セッションの開始から数えます。たとえば A 株の 1 時間足は 9:30、10:30、13:00、14:00 に始まります。

## 祝日と特別なルール

決まったルールでは表せないもの、たとえば祝日の休場や特定の日の短縮取引は、`calendar.bucket` を使って、各時刻がどの足に属するかを自分で決めます。

```ts
const holidays = new Set(['2026-10-01', '2026-10-02']);

createChart(container, {
  calendar: {
    timeZone: 'Asia/Shanghai',
    sessions: ['09:30-11:30', '13:00-15:00'],
    bucket: (time, interval, fallback) => {
      const date = new Date(time + 8 * 3_600_000).toISOString().slice(0, 10);
      return holidays.has(date) ? null : fallback(time);
    }
  }
});
```

その足の開始時刻を返します。`null` を返すと、その時刻は捨てられます。`fallback` は、ほかのカレンダー設定に従って計算した結果です。時刻が進むにつれて、返す時刻が過去に戻ってはいけません。

## このカレンダーを自分で使う

自分のコードでチャートと同じルールで時間をそろえたいとき、たとえばサーバーでローソク足を合成したり、ある時刻がどの足に属するかを判定したりするときは、`createCalendar()` を使います。

```ts
import { createCalendar } from '@kumochart-sdk/core';

const calendar = createCalendar({
  timeZone: 'Asia/Shanghai',
  sessions: ['09:30-11:30', '13:00-15:00']
});

calendar.bucket('2026-05-06T02:15:00Z', '1h'); // 北京時間 10:15 は 9:30 に始まる足に属するので、9:30 のタイムスタンプを返す
```

チャートがなくても使え、Node.js でも動きます。

チャートがあるときは、`chart.data.calendar()` がチャートの使っているカレンダー（`calendar` オプションにチャートのタイムゾーンを加えたもの）です。たとえばプラグインで足を取引日ごとにまとめるときに使います。オプションを変えると新しいものに替わるので、使うときに取得してください。
